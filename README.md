# 班级成绩管理系统

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE) ![Tauri](https://img.shields.io/badge/tauri-v2-ffc131.svg) ![Platform](https://img.shields.io/badge/platform-macOS%20%7C%20Windows%20%7C%20Linux-lightgrey.svg) ![Offline](https://img.shields.io/badge/offline-ready-3fb950.svg)

一个面向班主任 / 任课老师的离线成绩管理桌面应用。支持学生信息的增删改查、多场考试的自定义科目录入、总分与平均分自动计算、班级排名、按学生与按科目的双维度查询统计，以及数据的本地保存与 JSON / CSV 导入导出。

技术栈为 Tauri v2 + 原生 HTML / CSS / ES Module —— 没有框架、没有打包器、没有第三方运行时依赖，安装包约 5 MB，双击即用，不需要联网。

---

## 两种版本

本仓库提供两个实现，**共用同一份数据文件与同一套 JSON / CSV 格式**，可以随时切换着用同一份数据。

| | 图形版（仓库根目录） | 终端版（[`c/`](c/README.md)） |
|---|---|---|
| 技术栈 | Tauri v2 + HTML / CSS / ES Module | 纯 C，零第三方运行库 |
| 界面 | 原生窗口，表格 / 卡片 / 折线图 | 全屏字符界面（ncurses / Win32 控制台） |
| 可用平台 | macOS 10.13+、Windows 10+ | macOS、Linux、**Windows 7** |
| 适用场景 | 日常使用，推荐 | 需要在 Win7 上运行，或偏好纯键盘操作 |

> **为什么要单独做一个 C 版**：图形版依赖的 WebView2 已不支持 Windows 7
> （最后一个支持 Win7 的版本停在 109，2023 年 1 月后微软不再提供）。
> 要在 Win7 上使用，只能走原生程序这条路。

## 一、快速开始

### 方式一：直接下载可执行程序（推荐）

前往 [Releases](https://github.com/AyaseEli-Bing/grade-manager/releases/latest) 下载：

| 平台 | 文件 | 说明 |
|------|------|------|
| macOS（Apple Silicon） | `grade-manager-v1.0.0-macos-arm64.zip`（1.6 MB） | 解压后把 `班级成绩管理系统.app` 拖进「应用程序」。应用未签名，首次打开若提示「无法验证开发者」，在应用上**右键 → 打开**放行一次即可 |
| Windows | 需自行构建 | 把 `src-tauri/tauri.conf.json` 里的 `bundle.targets` 改成 `["nsis"]`，执行 `npm run build`，产物为 `.exe` 安装程序 |

### 方式二：从源码运行

```bash
npm install
npm run dev      # 开发模式启动，改代码即时生效
npm run build    # 打包为可分发应用
```

### 方式三：先用示例数据看效果

打开应用后，点击顶栏「导入」→ 选择 `examples/示例数据.json` → 选「替换全部数据」。
你会立刻得到 16 名学生、3 场考试、6 个科目的完整数据，可以直接体验排名、趋势图与科目统计。

也可以只用名单：顶栏「名单」→ 选择 `examples/成绩导入模板.csv`，一次导入 16 名学生及其期中成绩。

## 二、功能说明

### 1. 学生管理
- 新增 / 编辑 / 删除单个学生，或勾选后批量删除
- 字段：学号、姓名、性别、备注；姓名必填，学号用于导入时自动去重
- 表头可排序，搜索框按学号或姓名实时过滤
- 支持从 CSV 批量导入名单，导入时可选是否一并写入成绩列

### 2. 成绩录入
- 以「当前考试」为单位，行是学生、列是科目，直接在格子里输入分数
- 自动校验：只接受数字，超出 0 ~ 满分范围会提示并钳制到边界值
- 空格子表示缺考。**缺考科目的 0 分不会计入总分**，避免平均分被拉低导致失真
- 支持键盘操作：`Enter` 或 `↓` 下移一格，`↑` 上移一格
- 右上角进度条实时显示本场考试的录入完成度；底行显示每科的已录 / 缺考人数
- 分数按满分比例着色：≥90% 优秀、<60% 不及格

### 3. 统计排名
- 顶部 4 张指标卡：参考人数、全班平均分、最高总分、全科及格率
- **按学生排名**：名次 / 学号 / 姓名 / 各科分数 / 总分 / 平均分 / 得分率，任意列可点表头排序；前三名用金、银、铜色徽章区分
- **按科目统计**：每科一张卡片，含平均分、最高分、最低分、及格率、优秀率，并用条形图展示五个分数段的人数分布
- 点击任意学生行 → 右侧抽屉展示该生的各科成绩、**手写 SVG 绘制的历次考试总分趋势折线图**，以及每场考试的总分、名次与名次升降

### 4. 科目管理
- 自定义科目名称与满分（默认 100），适配小学到高中各种分值设置
- 上下移动调整科目顺序
- 删除科目时会明确警告将清除的关联成绩条数

### 5. 考试管理
- 顶栏下拉切换当前考试，点「管理考试」可新增 / 重命名 / 删除考试
- 每场考试可单独指定参考科目；不选表示考全部科目
- 考试日期用于成绩趋势图的排序

### 6. 数据保存与导入导出
- **自动保存**：任何修改在 400 毫秒内自动写入本地数据文件，侧边栏底部实时显示保存状态与数据文件路径
- **导出 JSON**：完整数据备份（含全部学生、科目、考试、成绩）
- **导出 CSV**：成绩表，可选「仅当前考试」或「全部考试」，带 UTF-8 BOM，Excel 直接打开不乱码
- **导入 JSON**：可选「替换全部数据」或「合并到现有数据」。合并规则为——学生按「学号 + 姓名」去重、科目按名称去重、考试按名称去重、成绩按「学生 + 科目」覆盖
- **导入 CSV**：批量导入学生名单（可含成绩）
- 导入前会自动在数据目录的 `backups/` 下创建一份带时间戳的备份，最多保留最近 10 份

数据文件位置：

| 平台 | 路径 |
|------|------|
| macOS | `~/Library/Application Support/cn.grade.manager/grades.json` |
| Windows | `%APPDATA%\cn.grade.manager\grades.json` |

同目录下的 `boot-status.json` 记录最近一次启动结果（`{"ok":true,"detail":"ok"}`）。
如果应用出现异常，先看这个文件——它是排查启动问题最快的入口。`backups/` 子目录存放自动备份。

## 三、CSV 导入格式

表头支持中文或英文，列的顺序无所谓，只要包含「姓名」列即可：

```csv
学号,姓名,性别,备注,语文,数学,英语,物理,化学,生物
2026001,陈嘉禾,男,班长,106,104,124,72,72,76
2026002,李思远,女,,141,121,121,92,84,87
```

- 与现有科目同名的列会被识别为成绩并写入当前考试；列名不匹配现有科目则忽略
- 单元格留空表示缺考
- 备注等字段若包含逗号，用英文双引号包裹即可
- 只有「姓名」，没有「学号」列也能导入

## 四、项目结构

```
grade-manager/
├── src/                          前端（直接被 Tauri 打包，无构建步骤）
│   ├── index.html                应用骨架
│   ├── design-tokens.css         设计 Token（604 行 / 391 个变量，全项目唯一允许写色值的文件）
│   ├── css/app.css               全部组件样式，只引用 Token，零硬编码颜色
│   └── js/
│       ├── app.js                入口：状态管理、视图路由、顶栏装配
│       ├── store.js              数据层底层：环境探测、文件读写、结构规范化
│       ├── calc.js               纯计算：总分 / 平均分 / 排名 / 单科统计 / 趋势
│       ├── io.js                 JSON / CSV 导入导出
│       ├── transfer.js           导入导出编排与数据合并策略
│       ├── shell.js              顶栏、侧边栏、启动失败兜底界面
│       ├── ui.js                 通用 UI 原语：转义 / 格式化 / 排序 / 焦点保持 / Toast / Modal
│       ├── form.js               表单弹窗、二次确认、多项选择
│       ├── charts.js             手写 SVG 折线图与分数段条形图
│       ├── icons.js              唯一图标集（25 枚内联描边 SVG）
│       └── views/                四个业务视图 + 考试管理 + 统计渲染片段
├── src-tauri/                    Rust 桌面外壳
│   ├── src/lib.rs                Tauri 命令：读写数据、原子保存、备份轮转、启动上报
│   ├── tauri.conf.json           窗口与打包配置
│   └── capabilities/default.json 最小权限：仅本地文件对话框，无网络权限
├── examples/                     示例数据与 CSV 模板
├── scripts/                      质量门禁与三层测试
└── docs/                         设计与使用文档
```

> **给二次开发者的重要提醒**：本项目前端没有打包器，浏览器 / WebView 里不存在
> `node_modules` 解析，因此**任何以 `./` 或 `../` 开头的相对路径以外的导入都会在打包后崩溃**。
> Tauri 能力请统一通过 `store.js` 里对 `window.__TAURI_INTERNALS__.invoke` 的封装访问，
> 不要直接 `import` 任何 `@tauri-apps/*` 包。改动后先跑 `npm run verify`。

## 五、开发与验收

```bash
npm run verify   # 质量门禁：模块图完整性、语法、emoji、硬编码颜色、单文件行数
npm test         # 三层端到端测试（共 62 项断言）
npm run icons    # 从 assets/icon.png 重新生成全套图标
```

`npm run verify` 强制执行五条项目铁律：

1. **模块图完整性** —— 导入路径必须以 `./` 或 `../` 开头，且目标文件真实存在。
   本项目没有打包器，裸模块说明符（如 `@tauri-apps/api/core`）在开发期不报错、
   只在打包后抛 `Failed to resolve module specifier` 白屏，所以必须靠静态检查拦下。
2. **禁止 emoji 作为功能图标** —— 全项目扫描，图标只能来自 `src/js/icons.js`
3. **禁止硬编码颜色** —— 除 `design-tokens.css` 外任何文件出现裸色值即失败
4. **单文件不超过 300 行** —— 保证模块可维护性
5. **JS 语法检查** —— ESM 统一按模块解析

`npm test` 分三层：

| 层 | 项数 | 覆盖内容 |
|----|------|----------|
| 逻辑层 | 21 | 总分只累计已录科目、同分同名次跳号、分数段人数守恒、悬空引用清理、CSV 引号转义、导入合并去重、示例数据可算完整排名 |
| 桌面链路 | 20 | 用桩替换 Tauri 桥，断言发给 Rust 的每条命令名、参数名、对话框选项形状；取消不写文件、底层报错向上抛、导出内容逐行比对 |
| 界面层 | 21 | jsdom 真实 DOM 中启动应用，覆盖四视图渲染、导航、KPI 数值、名次徽章、详情抽屉与趋势图、录入边界校验、防抖落盘、考试切换 |

**发布后的启动验证**（WebView 内的报错不会出现在终端，因此由应用自己写结果）：

```bash
rm -f "$HOME/Library/Application Support/cn.grade.manager/boot-status.json"
open "src-tauri/target/release/bundle/macos/班级成绩管理系统.app"
sleep 5
cat "$HOME/Library/Application Support/cn.grade.manager/boot-status.json"
# 期望 {"at":"...","detail":"ok","ok":true,"version":"1.0.0"}
```

文件不存在说明前端 JS 从未执行到底；`"ok":false` 的 `detail` 会写明具体原因。

## 六、设计约定

| 项 | 取值 |
|----|------|
| 主题 | 浅色单主题（办公场景长时间读数据更耐看） |
| 主色 | 深青 `#0F6C72`，白底对比度 6.2:1（AA 级） |
| 字体 | 系统栈 PingFang SC / Microsoft YaHei，数值列用等宽 + `tabular-nums` |
| 图标 | 25 枚内联描边 SVG，统一 1.75px 线宽、16 / 20 / 24px 三档尺寸 |
| 名次配色 | 金银铜降饱和色，前三名视觉区分，不使用图标或表情符号 |
| 动效 | 仅功能性反馈，时长 ≤ 240ms，尊重 `prefers-reduced-motion` |
| 权限 | 无网络访问，仅申请本地文件读写对话框权限 |

完整设计规范见 `docs/UIUX.md`。
